# Support

| You want to | Go to |
| --- | --- |
| Run Superaide on a Mac | [README: Run it](README.md#run-it) (`bash start.command`) |
| Put it on a server | [deploy/README.md](deploy/README.md) |
| Understand how it works | [docs/architecture.md](docs/architecture.md) and [docs/decisions/](docs/decisions/) |
| Report a bug or ask for a feature | [Open an issue](https://github.com/BeastxD7/superaide/issues/new/choose) and pick the form that fits |
| Report a vulnerability | [SECURITY.md](SECURITY.md). Never in a public issue |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

Superaide is maintained by [@BeastxD7](https://github.com/BeastxD7). Issues are triaged as time allows; security reports come first.

When asking for help, include the commit (`git rev-parse --short HEAD`), how you run it (`start.command`, `make`, Docker or a server), and the error. Remove personal data, tokens and keys first.
